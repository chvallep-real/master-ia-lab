# Directrices de Desarrollo y Asistencia IA

## Principios de Ingeniería
- Metodología: Spec Driven Development (SDD). No generar código de producción sin un archivo de especificación previo.
- Arquitectura: Clean Architecture. Separar la lógica de negocio pura de bases de datos y frameworks.
- Calidad: Tipado estático explícito y pruebas para cada regla de negocio.

## Entorno
- Sistema Operativo: Windows.
- Editor: Visual Studio Code.
- Formato de Commits: Conventional Commits (feat, fix, docs, chore, test).
